## ⚠️ Important Note About Windows Defender

Some users may receive a Windows Defender warning when running the executable. This is a known false positive that only occurs with Windows Defender (not detected by other antivirus software like Surfshark or Malwarebytes). This happens because:

- The application makes necessary blockchain network requests
- It includes contract interaction capabilities
- It's packaged as a standalone executable

The application is completely safe to use and has been scanned with multiple antivirus solutions. If you receive this warning, you can:

- Verify the executable using Windows Defender
- Build the application from source using the instructions in our README
- Contact us on Discord if you have any concerns
